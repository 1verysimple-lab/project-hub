Step 01 - Prerequisites

The Foundation

Ensure these two are installed. The script below checks for them, but it can't install them for you.

  • Git: Download Git for Windows

Step 02 - The Installer Script

Run the Batch File

This script uses native Windows commands. It creates the environment and installs the NVIDIA drivers automatically.

Action:

  1. Create a new folder on your PC (e.g., Desktop\AI_Lab).
  2. Open Notepad.
  3. Paste the code below into it.
  4. Save As: install.bat (Make sure "Save as type" is set to "All Files").
  5. Double-click install.bat.
@echo off
TITLE Blues AI Installer - MSI Cyborg 15
color 0A

echo ---------------------------------------------------
echo    STARTING COMFYUI SETUP FOR MSI CYBORG 15
echo ---------------------------------------------------
echo.

:: 1. Check if Git is installed
git --version >nul 2>&1
if %errorlevel% neq 0 (
    color 0C
    echo [ERROR] Git is not installed or not found in PATH.
    echo Please install Git for Windows first.
    pause
    exit /b
)

:: 2. Check if Python is installed
python --version >nul 2>&1
if %errorlevel% neq 0 (
    color 0C
    echo [ERROR] Python is not installed or not found in PATH.
    echo Please install Python 3.10 and check "Add to PATH".
    pause
    exit /b
)

if exist "ComfyUI" (

:: 4. Create Virtual Environment
if exist "venv" (
    echo [INFO] Venv already exists.

    python -m venv venv

:: 5. Install Dependencies (The heavy lifting)
echo.

Step 05 - Expansion Pack

Trying Other Models

ComfyUI is a universal engine. You can swap the "brain" to do different things. To use a new model, you simply download it, put it in the folder, and click "Refresh" in ComfyUI.

1. Generating Source Images (SDXL)

SVD creates video from images. You need high-quality images first. For this, you want an SDXL model.

Recommended: Juggernaut XL

What it does: Creates photorealistic images (1024x1024) perfect for feeding into SVD.

How to install:

  1. Download: Juggernaut XL on Civitai (Look for the "Download" button, ~6GB).
  2. Place file in: ComfyUI\models\checkpoints\
  3. How to use: In ComfyUI, double-click background -> Search "Load Checkpoint" -> Select Juggernaut.

2. Advanced Animation (AnimateDiff)

What it does: Unlike SVD (which predicts movement from one image), AnimateDiff creates cartoons or stylized loops from text prompts.

Recommended: AnimateDiff Motion Module (v1.5 v2)

How to install (Different Folder!):

  1. Download: mm_sd_v15_v2.ckpt
  2. Place file in: ComfyUI\custom_nodes\ComfyUI-AnimateDiff-Evolved\models\
    (Note: You may need to install the "AnimateDiff Evolved" custom node first via "ComfyUI Manager" if you get deep into this).
Pro Tip: Always look for files ending in .safetensors. They are faster to load and safer than .ckpt files.
