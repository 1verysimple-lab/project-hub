The "Secret Weapon" for Unity

Because fixing compiler errors should be the computer's job, not yours.

What is this?

Blues thinks you're working too hard on cryptic Unity errors. This isn't just another ChatGPT window. This is Gemini CLI. It lives inside your project folder.

  • It can read your C# scripts directly (no copy-pasting).
  • It sees the exact error Unity is shouting about.
  • It suggests fixes that actually fit your specific game logic.

"But I hate the Terminal..."

Don't worry. The "Terminal" (or PowerShell) is just the engine room. It looks scary because it's black with white text, but it's actually just a chat room where the only other participant is your computer.

Instead of clicking buttons, you type text. That's it.
You type: gemini fix this error
It replies: You missed a semicolon in Player.cs. Want me to add it?

Let's set it up

1. Where is your project?

We need to install the brain. Click the button below to generate the installer script.

✓ Script downloaded! Check your downloads folder.

2. Install it

  1. Move the downloaded file (Setup-Gemini.ps1) into your main Unity Project folder.
  2. Right-click the file and select "Run with PowerShell".
  3. A blue/black window will open. It might ask for permission—type Y or A and hit Enter.
  4. Wait for it to finish installing "Node.js" and "Gemini".

3. How to use it efficiently

Whenever Unity gives you an error:

  1. Go to your Project folder in Windows Explorer.
  2. Hold Shift and Right-Click on empty space in the folder.
  3. Select "Open PowerShell window here" (or "Open in Terminal").
  4. Type gemini and hit Enter.
  5. Paste your error message and hit Enter.
